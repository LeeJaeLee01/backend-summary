# Q16 — Data lake visualization with access control

## Question

**EN:** A company hosts a data lake on AWS. The data lake consists of data in Amazon S3 and Amazon RDS for PostgreSQL. The company needs a reporting solution that provides data visualization and includes all the data sources within the data lake. Only the company's management team should have full access to all the visualizations. The rest of the company should have only limited access. Which solution will meet these requirements?

**VI:** Một công ty host **data lake** trên AWS, gồm dữ liệu trong **Amazon S3** và **Amazon RDS for PostgreSQL**. Công ty cần giải pháp **báo cáo + visualization** tích hợp **tất cả nguồn dữ liệu** trong data lake. Chỉ **đội quản lý (management)** được **full access** mọi visualization; phần còn lại của công ty chỉ có **quyền hạn chế**. Giải pháp nào đáp ứng yêu cầu này?

---

## Options

### A

**EN:** Create an analysis in Amazon QuickSight. Connect all the data sources and create new datasets. Publish dashboards to visualize the data. Share the dashboards with the appropriate IAM roles.

**VI:** **QuickSight** analysis, connect nguồn, dataset, publish dashboard. Share với **IAM roles**.

### B

**EN:** Create an analysis in Amazon QuickSight. Connect all the data sources and create new datasets. Publish dashboards to visualize the data. Share the dashboards with the appropriate users and groups.

**VI:** **QuickSight** analysis, connect nguồn, dataset, publish dashboard. Share với **users và groups**.

### C

**EN:** Create an AWS Glue table and crawler for the data in Amazon S3. Create an AWS Glue extract, transform, and load (ETL) job to produce reports. Publish the reports to Amazon S3. Use S3 bucket policies to limit access to the reports.

**VI:** **Glue** crawler/ETL → report lên **S3**, giới hạn bằng bucket policy.

### D

**EN:** Create an AWS Glue table and crawler for the data in Amazon S3. Use Amazon Athena Federated Query to access data within Amazon RDS for PostgreSQL. Generate reports by using Amazon Athena. Publish the reports to Amazon S3. Use S3 bucket policies to limit access to the reports.

**VI:** Glue + **Athena Federated Query** (RDS) → report S3, bucket policy.

---

## Answer

**Đáp án: B**

**Note:** Data lake multi-source (S3 + RDS), cần dashboard + phân quyền management vs nhân viên → **Amazon QuickSight** share theo **users/groups** (không phải IAM roles).

| Option | Vì sao loại / chọn |
|--------|---------------------|
| A | QuickSight share theo **users/groups QuickSight**, không phải share dashboard trực tiếp qua **IAM roles** như mô tả. |
| **B ✅** | **QuickSight** = visualization managed, connect S3 + RDS. **Share users/groups** + row/column level security — phù hợp management full vs limited. |
| C | Glue ETL + file S3 — không interactive visualization/dashboard như yêu cầu. |
| D | Athena + S3 reports — tương tự, thiếu BI dashboard và phân quyền visualization linh hoạt. |

**Ghi nhớ:** BI dashboard multi-source + phân quyền user → **Amazon QuickSight**.
