# Q1 — Global data aggregation to S3

## Question

**EN:** A company collects data for temperature, humidity, and atmospheric pressure in cities across multiple continents. The average volume of data that the company collects from each site daily is 500 GB. Each site has a high-speed Internet connection. The company wants to aggregate the data from all these global sites as quickly as possible in a single Amazon S3 bucket. The solution must minimize operational complexity. Which solution meets these requirements?

**VI:** Một công ty thu thập dữ liệu về nhiệt độ, độ ẩm và áp suất khí quyển tại các thành phố trên nhiều châu lục. Lượng dữ liệu trung bình thu thập từ mỗi site mỗi ngày là **500 GB**. Mỗi site có **kết nối Internet tốc độ cao**. Công ty muốn **tổng hợp dữ liệu** từ tất cả các site toàn cầu **càng nhanh càng tốt** vào **một S3 bucket duy nhất**. Giải pháp phải **giảm thiểu độ phức tạp vận hành**. Giải pháp nào đáp ứng các yêu cầu này?

---

## Options

### A

**EN:** Turn on S3 Transfer Acceleration on the destination S3 bucket. Use multipart uploads to directly upload site data to the destination S3 bucket.

**VI:** Bật **S3 Transfer Acceleration** trên S3 bucket đích. Dùng **multipart upload** để upload trực tiếp dữ liệu từ site lên bucket đích.

### B

**EN:** Upload the data from each site to an S3 bucket in the closest Region. Use S3 Cross-Region Replication to copy objects to the destination S3 bucket. Then remove the data from the origin S3 bucket.

**VI:** Upload dữ liệu từ mỗi site lên một S3 bucket ở **Region gần nhất**. Dùng **S3 Cross-Region Replication (CRR)** để copy object sang bucket đích, sau đó **xóa dữ liệu** ở bucket nguồn.

### C

**EN:** Schedule AWS Snowball Edge Storage Optimized device jobs daily to transfer data from each site to the closest Region. Use S3 Cross-Region Replication to copy objects to the destination S3 bucket.

**VI:** Lên lịch job **AWS Snowball Edge Storage Optimized** hàng ngày để chuyển dữ liệu từ mỗi site tới Region gần nhất. Dùng **S3 Cross-Region Replication** để copy object sang bucket đích.

### D

**EN:** Upload the data from each site to an Amazon EC2 instance in the closest Region. Store the data in an Amazon Elastic Block Store (Amazon EBS) volume. At regular intervals, take an EBS snapshot and copy it to the Region that contains the destination S3 bucket. Restore the EBS volume in that Region.

**VI:** Upload dữ liệu từ mỗi site lên **EC2 instance** ở Region gần nhất. Lưu dữ liệu trên **Amazon EBS volume**. Theo chu kỳ, tạo **EBS snapshot**, copy snapshot sang Region chứa bucket đích, rồi **restore EBS volume** ở Region đó.

---

## Answer

**Đáp án: A**

**Note:** Nhiều site toàn cầu, mỗi site 500 GB/ngày, có Internet nhanh, cần gom vào một S3 bucket nhanh và ít phức tạp → chọn **S3 Transfer Acceleration + multipart upload** upload thẳng lên bucket đích; không cần Snowball hay bước replicate trung gian.

| Option | Vì sao loại / chọn |
|--------|---------------------|
| **A ✅** | Internet tốc độ cao → upload trực tiếp được. **Transfer Acceleration** tối ưu tốc độ từ site toàn cầu qua CloudFront edge. **Multipart upload** phù hợp file lớn (500 GB). Ít thành phần vận hành nhất. |
| B | Thêm bước CRR + xóa origin → phức tạp hơn, chậm hơn (2 hop). |
| C | Snowball dùng khi **băng thông hạn chế** hoặc offline — không phù hợp khi đã có Internet nhanh. |
| D | EC2 + EBS + snapshot + restore — vận hành nặng, không phải pattern upload S3. |
