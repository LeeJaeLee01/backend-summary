# Q29 — Multi-Region VoIP UDP: lowest latency + failover

## Question

**EN:** A company provides a Voice over Internet Protocol (VoIP) service that uses UDP connections. The service consists of Amazon EC2 instances that run in an Auto Scaling group. The company has deployments across multiple AWS Regions. The company needs to route users to the Region with the lowest latency. The company also needs automated failover between Regions. Which solution will meet these requirements?

**VI:** Một công ty cung cấp dịch vụ **VoIP dùng kết nối UDP**. Dịch vụ gồm **EC2** trong **Auto Scaling group**, triển khai trên **nhiều AWS Region**. Công ty cần route user tới **Region có latency thấp nhất** và **failover tự động** giữa các Region. Giải pháp nào phù hợp?

---

## Options

### A

**EN:** Deploy a Network Load Balancer (NLB) and an associated target group. Associate the target group with the Auto Scaling group. Use the NLB as an AWS Global Accelerator endpoint in each Region.

**VI:** **NLB** + target group (ASG). Dùng NLB làm **Global Accelerator endpoint** mỗi Region.

### B

**EN:** Deploy an Application Load Balancer (ALB) and an associated target group. Associate the target group with the Auto Scaling group. Use the ALB as an AWS Global Accelerator endpoint in each Region.

**VI:** **ALB** + target group. ALB làm Global Accelerator endpoint mỗi Region.

### C

**EN:** Deploy a Network Load Balancer (NLB) and an associated target group. Associate the target group with the Auto Scaling group. Create an Amazon Route 53 latency record that points to aliases for each NLB. Create an Amazon CloudFront distribution that uses the latency record as an origin.

**VI:** NLB + ASG. **Route 53 latency record** → NLB. **CloudFront** dùng latency record làm origin.

### D

**EN:** Deploy an Application Load Balancer (ALB) and an associated target group. Associate the target group with the Auto Scaling group. Create an Amazon Route 53 weighted record that points to aliases for each ALB. Deploy an Amazon CloudFront distribution that uses the weighted record as an origin.

**VI:** ALB + **Route 53 weighted** + CloudFront.

---

## Answer

**Đáp án: A**

**Note:** VoIP **UDP** multi-Region, cần latency thấp + failover → **NLB** (hỗ trợ UDP) làm endpoint **AWS Global Accelerator** mỗi Region; ALB không hỗ trợ UDP.

| Option | Vì sao loại / chọn |
|--------|---------------------|
| **A ✅** | **UDP** cần **NLB** (ALB không hỗ trợ UDP). **Global Accelerator** = anycast, route latency + **health-based failover** multi-Region — đúng VoIP. |
| B | **ALB** không support UDP native — loại ngay. |
| C | CloudFront không phù hợp **UDP VoIP** realtime; kiến trúc sai. |
| D | ALB + weighted — không UDP; weighted không phải latency routing + failover GA. |

**Ghi nhớ:** UDP/TCP non-HTTP multi-Region + latency + failover → **NLB + Global Accelerator**.
