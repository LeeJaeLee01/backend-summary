# Q17 — EC2 access to S3 bucket

## Question

**EN:** A company is implementing a new business application. The application runs on two Amazon EC2 instances and uses an Amazon S3 bucket for document storage. A solutions architect needs to ensure that the EC2 instances can access the S3 bucket. What should the solutions architect do to meet this requirement?

**VI:** App mới chạy trên **2 EC2 instance**, lưu tài liệu trên **S3**. Cần đảm bảo EC2 **truy cập được S3**. Làm gì?

---

## Options

### A

**EN:** Create an IAM role that grants access to the S3 bucket. Attach the role to the EC2 instances.

**VI:** Tạo **IAM role** có quyền S3 bucket. **Gắn role** vào EC2 instances.

### B

**EN:** Create an IAM policy that grants access to the S3 bucket. Attach the policy to the EC2 instances.

**VI:** Tạo **IAM policy** quyền S3. **Gắn policy** trực tiếp vào EC2 instances.

### C

**EN:** Create an IAM group that grants access to the S3 bucket. Attach the group to the EC2 instances.

**VI:** Tạo **IAM group** quyền S3. Gắn group vào EC2.

### D

**EN:** Create an IAM user that grants access to the S3 bucket. Attach the user account to the EC2 instances.

**VI:** Tạo **IAM user** quyền S3. Gắn user vào EC2.

---

## Answer

**Đáp án: A**

| Option | Vì sao loại / chọn |
|--------|---------------------|
| **A ✅** | **IAM role** (instance profile) gắn EC2 — SDK tự lấy temporary credential, **best practice**, không hardcode key. |
| B | **Không attach policy trực tiếp** lên EC2 — policy gắn vào **role/user/group**, role gắn EC2. |
| C | IAM group cho **users**, không attach vào EC2 instance. |
| D | IAM user + key trên EC2 — anti-pattern (rotation, leak risk). |

**Ghi nhớ:** EC2 → AWS API (S3…) → **IAM role / instance profile**.
