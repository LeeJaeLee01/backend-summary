# Q32 — Most cost-effective static website hosting

## Question

**EN:** A development team needs to host a website that will be accessed by other teams. The website contents consist of HTML, CSS, client-side JavaScript, and images. Which method is the MOST cost-effective for hosting the website?

**VI:** Team dev cần host website cho team khác truy cập. Nội dung: **HTML, CSS, client-side JavaScript, images** (static). Cách host **tiết kiệm chi phí nhất**?

---

## Options

### A

**EN:** Containerize the website and host it in AWS Fargate.

**VI:** **Containerize** website, host trên **AWS Fargate**.

### B

**EN:** Create an Amazon S3 bucket and host the website there.

**VI:** Tạo **S3 bucket** host website (static website hosting).

### C

**EN:** Deploy a web server on an Amazon EC2 instance to host the website.

**VI:** Deploy **web server trên EC2**.

### D

**EN:** Configure an Application Load Balancer with an AWS Lambda target that uses the Express.js framework.

**VI:** **ALB** + **Lambda** (Express.js).

---

## Answer

**Đáp án: B**

| Option | Vì sao loại / chọn |
|--------|---------------------|
| A | Fargate — trả tiền container 24/7 cho static files — overkill. |
| **B ✅** | **S3 static website hosting** — rẻ nhất cho HTML/CSS/JS/images; không server manage; có thể thêm CloudFront sau. |
| C | EC2 24/7 — tốn compute dù traffic thấp. |
| D | ALB + Lambda — phức tạp, đắt cho static content thuần. |

**Ghi nhớ:** Static site → **S3** (+ CloudFront nếu cần CDN).
