# Q12 — CloudFront for static (S3) + dynamic (ALB)

## Question

**EN:** A global company hosts its web application on Amazon EC2 instances behind an Application Load Balancer (ALB). The web application has static data and dynamic data. The company stores its static data in an Amazon S3 bucket. The company wants to improve performance and reduce latency for the static data and dynamic data. The company is using its own domain name registered with Amazon Route 53. What should a solutions architect do to meet these requirements?

**VI:** Một công ty global host **web application** trên **EC2** sau **Application Load Balancer (ALB)**. Ứng dụng có **dữ liệu tĩnh (static)** và **dữ liệu động (dynamic)**; static lưu trong **Amazon S3 bucket**. Công ty muốn **cải thiện performance và giảm latency** cho cả static và dynamic. Công ty dùng **domain riêng** đăng ký trên **Amazon Route 53**. **Solutions architect** nên làm gì để đáp ứng các yêu cầu này?

---

## Options

### A

**EN:** Create an Amazon CloudFront distribution that has the S3 bucket and the ALB as origins. Configure Route 53 to route traffic to the CloudFront distribution.

**VI:** Tạo **CloudFront** với **S3** và **ALB** làm origins. **Route 53** trỏ traffic tới CloudFront.

### B

**EN:** Create an Amazon CloudFront distribution that has the ALB as an origin. Create an AWS Global Accelerator standard accelerator that has the S3 bucket as an endpoint. Configure Route 53 to route traffic to the CloudFront distribution.

**VI:** CloudFront origin = ALB. **Global Accelerator** endpoint = S3. Route 53 → CloudFront.

### C

**EN:** Create an Amazon CloudFront distribution that has the S3 bucket as an origin. Create an AWS Global Accelerator standard accelerator that has the ALB and the CloudFront distribution as endpoints. Create a custom domain name that points to the accelerator DNS name. Use the custom domain name as an endpoint for the web application.

**VI:** CloudFront origin = S3. Global Accelerator endpoints = ALB + CloudFront. Custom domain → accelerator.

### D

**EN:** Create an Amazon CloudFront distribution that has the ALB as an origin. Create an AWS Global Accelerator standard accelerator that has the S3 bucket as an endpoint. Create two domain names. Point one domain name to the CloudFront DNS name for dynamic content. Point the other domain name to the accelerator DNS name for static content. Use the domain names as endpoints for the web application.

**VI:** CloudFront → ALB (dynamic). Global Accelerator → S3 (static). **Hai domain** riêng.

---

## Answer

**Đáp án: A**

**Note:** Static trên S3 + dynamic qua ALB, cần giảm latency toàn cầu → **CloudFront** với **hai origins (S3 + ALB)**, Route 53 trỏ về distribution — một điểm vào, cache ở edge.

| Option | Vì sao loại / chọn |
|--------|---------------------|
| **A ✅** | **CloudFront** cache static từ **S3** + dynamic từ **ALB** (edge gần user). **Một distribution**, Route 53 alias → CloudFront — pattern chuẩn global web. |
| B | Global Accelerator **không** dùng S3 làm endpoint trực tiếp kiểu này; kiến trúc lẫn lộn. |
| C | Phức tạp không cần thiết — GA + CF chồng chéo, overhead vận hành. |
| D | Hai domain tách static/dynamic — UX và vận hành kém; không tối ưu latency đơn giản nhất. |

**Ghi nhớ:** Static S3 + dynamic ALB + global latency → **CloudFront multi-origin** + Route 53.
