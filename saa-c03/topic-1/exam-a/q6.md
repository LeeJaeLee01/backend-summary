# Q6 — Migrate 70 TB NFS on-premises to S3

## Question

**EN:** A company uses NFS to store large video files in on-premises network attached storage. Each video file ranges in size from 1 MB to 500 GB. The total storage is 70 TB and is no longer growing. The company decides to migrate the video files to Amazon S3. The company must migrate the video files as soon as possible while using the least possible network bandwidth.

**VI:** Công ty dùng **NFS** lưu video lớn on-premises. Mỗi file **1 MB – 500 GB**, tổng **70 TB**, không còn tăng. Cần migrate sang **Amazon S3** **càng sớm càng tốt** và dùng **ít băng thông mạng nhất**.

---

## Options

### A

**EN:** Create an S3 bucket. Create an IAM role that has permissions to write to the S3 bucket. Use the AWS CLI to copy all files locally to the S3 bucket.

**VI:** Tạo S3 bucket + IAM role ghi S3. Dùng **AWS CLI** copy toàn bộ file lên S3 qua mạng.

### B

**EN:** Create an AWS Snowball Edge job. Receive a Snowball Edge device on premises. Use the Snowball Edge client to transfer data to the device. Return the device so that AWS can import the data into Amazon S3.

**VI:** Tạo job **AWS Snowball Edge**. Nhận thiết bị on-premises, copy dữ liệu lên thiết bị, gửi lại AWS để import vào S3.

### C

**EN:** Deploy an S3 File Gateway on premises. Create a public service endpoint to connect to the S3 File Gateway. Create an S3 bucket. Create a new NFS file share on the S3 File Gateway. Point the new file share to the S3 bucket. Transfer the data from the existing NFS file share to the S3 File Gateway.

**VI:** Triển khai **S3 File Gateway** on-premises, endpoint public, tạo NFS share trỏ S3, chuyển dữ liệu từ NFS hiện tại sang gateway.

### D

**EN:** Set up an AWS Direct Connect connection between the on-premises network and AWS. Deploy an S3 File Gateway on premises. Create a public virtual interface (VIF) to connect to the S3 File Gateway. Create an S3 bucket. Create a new NFS file share on the S3 File Gateway. Point the new file share to the S3 bucket. Transfer the data from the existing NFS file share to the S3 File Gateway.

**VI:** Thiết lập **Direct Connect** + S3 File Gateway + VIF public, NFS share trỏ S3, chuyển dữ liệu qua gateway.

---

## Answer

**Đáp án: B**

| Option | Vì sao loại / chọn |
|--------|---------------------|
| A | 70 TB qua internet/WAN — **tốn băng thông**, chậm, không “least bandwidth”. |
| **B ✅** | **Snowball Edge** = vận chuyển vật lý — **gần như không dùng băng thông** site, phù hợp one-time migration lớn (TB), nhanh hơn link chậm. |
| C | File Gateway vẫn **upload qua mạng** lên S3 — tốn bandwidth; gateway hay dùng hybrid ongoing, không tối ưu “migrate ASAP + least bandwidth”. |
| D | Direct Connect + gateway — chi phí/thời gian setup cao; vẫn transfer qua mạng, không ít bandwidth bằng Snowball cho bulk one-shot. |

**Ghi nhớ:** Migrate TB+, hạn chế bandwidth → **Snowball / Snowmobile**. Online lớn + link tốt → DataSync / CLI.
