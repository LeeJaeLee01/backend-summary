# Q9 — SMB file server: extend storage + lifecycle

## Question

**EN:** A company is running an SMB file server in its data center. The file server stores large files that are accessed frequently for the first few days after the files are created. After 7 days the files are rarely accessed. The total data size is increasing and is close to the company's total storage capacity. A solutions architect must increase the company's available storage space without losing low-latency access to the most recently accessed files. The solutions architect must also provide file lifecycle management to avoid future storage issues. Which solution will meet these requirements?

**VI:** Công ty chạy **SMB file server** on-premises. File lớn, **truy cập nhiều vài ngày đầu**, sau **7 ngày** hiếm khi dùng. Dung lượng tăng, sắp hết storage. Cần **mở rộng dung lượng** mà vẫn **truy cập nhanh** file mới, và có **lifecycle** tránh hết chỗ sau này. Giải pháp nào phù hợp?

---

## Options

### A

**EN:** Use AWS DataSync to copy data that is older than 7 days from the SMB file server to AWS.

**VI:** Dùng **AWS DataSync** copy dữ liệu **> 7 ngày** từ SMB server lên AWS.

### B

**EN:** Create an Amazon S3 File Gateway to extend the company's storage space. Create an S3 Lifecycle policy to transition the data to S3 Glacier Deep Archive after 7 days.

**VI:** Tạo **S3 File Gateway** mở rộng storage. **S3 Lifecycle** chuyển dữ liệu sang **S3 Glacier Deep Archive** sau 7 ngày.

### C

**EN:** Create an Amazon FSx for Windows File Server file system to extend the company's storage space.

**VI:** Tạo **Amazon FSx for Windows File Server** để mở rộng storage.

### D

**EN:** Install a utility on each user's computer to access Amazon S3. Create an S3 Lifecycle policy to transition the data to S3 Glacier Flexible Retrieval after 7 days.

**VI:** Cài utility trên **mỗi máy user** truy cập S3. Lifecycle sang **Glacier Flexible Retrieval** sau 7 ngày.

---

## Answer

**Đáp án: B**

| Option | Vì sao loại / chọn |
|--------|---------------------|
| A | DataSync = copy/sync — không mở rộng SMB **transparent** + lifecycle tự động on-going như gateway. |
| **B ✅** | **S3 File Gateway** = SMB/NFS on-prem **mở rộng** lên S3; file mới cache local **low latency**; **Lifecycle → Glacier Deep Archive** sau 7 ngày — rẻ, tự động tiering. |
| C | FSx mở rộng được nhưng **đắt** cho archive-heavy; không có lifecycle tier S3/Glacier như đề yêu cầu. |
| D | Utility từng máy — **operational overhead** cao, không thay SMB server tập trung. |

**Ghi nhớ:** On-prem file share + tier cold data → **Storage Gateway (File Gateway)** + **S3 Lifecycle**.
