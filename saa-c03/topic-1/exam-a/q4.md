# Q4 — Private EC2 access to S3 (no internet)

## Question

**EN:** An application runs on an Amazon EC2 instance in a VPC. The application processes logs that are stored in an Amazon S3 bucket. The EC2 instance needs to access the S3 bucket without connectivity to the internet. Which solution will provide private network connectivity to Amazon S3?

**VI:** Một ứng dụng chạy trên **EC2 instance** trong **VPC**. Ứng dụng xử lý log lưu trong **S3 bucket**. EC2 cần truy cập S3 **không qua internet**. Giải pháp nào cung cấp **kết nối mạng riêng (private)** tới Amazon S3?

---

## Options

### A

**EN:** Create a gateway VPC endpoint to the S3 bucket.

**VI:** Tạo **gateway VPC endpoint** tới S3.

### B

**EN:** Stream the logs to Amazon CloudWatch Logs. Export the logs to the S3 bucket.

**VI:** Stream log lên **Amazon CloudWatch Logs**, rồi export sang S3 bucket.

### C

**EN:** Create an instance profile on Amazon EC2 to allow S3 access.

**VI:** Tạo **instance profile** trên EC2 để cho phép truy cập S3.

### D

**EN:** Create an Amazon API Gateway API with a private link to access the S3 endpoint.

**VI:** Tạo **API Gateway** với **PrivateLink** để truy cập S3 endpoint.

---

## Answer

**Đáp án: A**

| Option | Vì sao loại / chọn |
|--------|---------------------|
| **A ✅** | **Gateway VPC endpoint** cho S3 — traffic EC2 → S3 đi trong mạng AWS, **không cần Internet Gateway / NAT**. Thêm route table trỏ prefix list S3. Pattern chuẩn SAA cho private subnet access S3. |
| B | Đổi luồng log qua CloudWatch — không giải quyết EC2 cần đọc/ghi S3 trực tiếp, không phải private connectivity tới S3 từ VPC. |
| C | **Instance profile** = IAM quyền gọi API S3, **không** tạo đường mạng private. EC2 private subnet vẫn cần endpoint hoặc NAT để reach S3. |
| D | API Gateway PrivateLink không phải cách thiết kế để EC2 trong VPC truy cập S3 object storage — phức tạp, sai pattern. |

**Ghi nhớ SAA:**

```
EC2 trong VPC private, cần S3/DynamoDB không internet
  → Gateway VPC endpoint (S3, DynamoDB)
  → Interface VPC endpoint (nhiều service khác — PrivateLink)
```
