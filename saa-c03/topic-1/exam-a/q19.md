# Q19 — Third-party firewall appliance inline inspection

## Question

**EN:** A company has a three-tier web application that is deployed on AWS. The web servers are deployed in a public subnet in a VPC. The application servers and database servers are deployed in private subnets in the same VPC. The company has deployed a third-party virtual firewall appliance from AWS Marketplace in an inspection VPC. The appliance is configured with an IP interface that can accept IP packets. A solutions architect needs to integrate the web application with the appliance to inspect all traffic to the application before the traffic reaches the web server. Which solution will meet these requirements with the LEAST operational overhead?

**VI:** App 3-tier: **web** public subnet, **app + DB** private subnet. Có **firewall appliance bên thứ ba** (Marketplace) trong **inspection VPC**, nhận IP packets. Cần **inspect mọi traffic** tới app **trước web server**, **ít overhead vận hành nhất**.

---

## Options

### A

**EN:** Create a Network Load Balancer in the public subnet of the application's VPC to route the traffic to the appliance for packet inspection.

**VI:** **NLB** public subnet app VPC → route traffic tới appliance inspect.

### B

**EN:** Create an Application Load Balancer in the public subnet of the application's VPC to route the traffic to the appliance for packet inspection.

**VI:** **ALB** public subnet → route tới appliance inspect.

### C

**EN:** Deploy a transit gateway in the inspection VPC. Configure route tables to route the incoming packets through the transit gateway.

**VI:** **Transit Gateway** inspection VPC, route table điều hướng packet.

### D

**EN:** Deploy a Gateway Load Balancer in the inspection VPC. Create a Gateway Load Balancer endpoint to receive the incoming packets and forward the packets to the appliance.

**VI:** **Gateway Load Balancer** trong inspection VPC. **GWLB endpoint** nhận packet, forward tới appliance.

---

## Answer

**Đáp án: D**

| Option | Vì sao loại / chọn |
|--------|---------------------|
| A | NLB không tích hợp **third-party inline appliance** chuẩn GENEVE như GWLB. |
| B | ALB layer 7 — không phải path inline packet inspection appliance IP. |
| C | TGW routing phức tạp, không phải pattern marketplace firewall **ít overhead** nhất. |
| **D ✅** | **Gateway Load Balancer** + **GWLB endpoint** = pattern chuẩn **inline third-party appliances** (firewall, IDS) — transparent inspection, managed scaling. |

**Ghi nhớ:** Marketplace virtual appliance inline → **GWLB** (khác **Network Firewall** managed AWS — câu 15).
