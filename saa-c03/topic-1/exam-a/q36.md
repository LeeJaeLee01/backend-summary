# Q36 — Multi-Region S3 + same customer managed KMS key

## Question

**EN:** A company is building an application in the AWS Cloud. The application will store data in Amazon S3 buckets in two AWS Regions. The company must use an AWS Key Management Service (AWS KMS) customer managed key to encrypt all data that is stored in the S3 buckets. The data in both S3 buckets must be encrypted and decrypted with the same KMS key. The data and the key must be stored in each of the two Regions. Which solution will meet these requirements with the LEAST operational overhead?

**VI:** App lưu data trong **S3 hai Region**. Bắt buộc **customer managed KMS** mã hóa mọi object. Data **cả hai bucket** encrypt/decrypt bằng **cùng một KMS key**. Key và data phải có ở **mỗi Region**. Giải pháp **ít overhead vận hành nhất**?

---

## Options

### A

**EN:** Create an S3 bucket in each Region. Configure the S3 buckets to use server-side encryption with Amazon S3 managed encryption keys (SSE-S3). Configure replication between the S3 buckets.

**VI:** S3 mỗi Region, **SSE-S3**, **replication** giữa bucket.

### B

**EN:** Create a customer managed multi-Region KMS key. Create an S3 bucket in each Region. Configure replication between the S3 buckets. Configure the application to use the KMS key with client-side encryption.

**VI:** **Multi-Region KMS key**, S3 mỗi Region, replication, app dùng **client-side encryption**.

### C

**EN:** Create a customer managed KMS key and an S3 bucket in each Region. Configure the S3 buckets to use server-side encryption with Amazon S3 managed encryption keys (SSE-S3). Configure replication between the S3 buckets.

**VI:** **CMK** + S3 mỗi Region, **SSE-S3**, replication.

### D

**EN:** Create a customer managed KMS key and an S3 bucket in each Region. Configure the S3 buckets to use server-side encryption with AWS KMS keys (SSE-KMS). Configure replication between the S3 buckets.

**VI:** **CMK** + S3 mỗi Region, **SSE-KMS**, replication.

---

## Answer

**Đáp án: D**

| Option | Vì sao loại / chọn |
|--------|---------------------|
| A | **SSE-S3** — không phải **customer managed KMS** như yêu cầu. |
| B | Multi-Region KMS đúng hướng nhưng **client-side encryption** — app phải encrypt/decrypt, **overhead cao** hơn SSE-KMS. |
| C | Có CMK nhưng bucket dùng **SSE-S3** — mâu thuẫn yêu cầu CMK encrypt data. |
| **D ✅** | **SSE-KMS** với **customer managed key** (dùng **multi-Region key + replica** ở Region thứ hai) + **S3 CRR** — cùng key material, encrypt at rest server-side, ít thay đổi app nhất. |

**Ghi nhớ:** Multi-Region S3 + cùng CMK → **SSE-KMS (MRK)** + **cross-Region replication**. Tránh client-side nếu đề hỏi least overhead.
