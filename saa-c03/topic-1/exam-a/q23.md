# Q23 — Backup lifecycle: hot 1 month, then archive forever

## Question

**EN:** A company is storing backup files by using Amazon S3 Standard storage. The files are accessed frequently for 1 month. However, the files are not accessed after 1 month. The company must keep the files indefinitely. Which storage solution will meet these requirements MOST cost-effectively?

**VI:** Một công ty lưu file backup bằng **Amazon S3 Standard**. File được **truy cập thường xuyên trong 1 tháng đầu**, sau đó **không còn truy cập**. Công ty phải **giữ file vĩnh viễn**. Giải pháp storage nào **tiết kiệm chi phí nhất**?

---

## Options

### A

**EN:** Configure S3 Intelligent-Tiering to automatically migrate objects.

**VI:** Cấu hình **S3 Intelligent-Tiering** tự chuyển tier.

### B

**EN:** Create an S3 Lifecycle configuration to transition objects from S3 Standard to S3 Glacier Deep Archive after 1 month.

**VI:** **S3 Lifecycle**: Standard → **S3 Glacier Deep Archive** sau 1 tháng.

### C

**EN:** Create an S3 Lifecycle configuration to transition objects from S3 Standard to S3 Standard-Infrequent Access (S3 Standard-IA) after 1 month.

**VI:** Lifecycle: Standard → **S3 Standard-IA** sau 1 tháng.

### D

**EN:** Create an S3 Lifecycle configuration to transition objects from S3 Standard to S3 One Zone-Infrequent Access (S3 One Zone-IA) after 1 month.

**VI:** Lifecycle: Standard → **S3 One Zone-IA** sau 1 tháng.

---

## Answer

**Đáp án: B**

**Note:** Hot 1 tháng, sau đó archive vĩnh viễn, ít access → **Lifecycle** chuyển sang **Glacier Deep Archive** — rẻ nhất long-term storage.

| Option | Vì sao loại / chọn |
|--------|---------------------|
| A | Intelligent-Tiering tốt cho pattern không chắc; đề **rõ** sau 1 tháng không access → Glacier rẻ hơn. |
| **B ✅** | **Glacier Deep Archive** = rẻ nhất long-term archive, giữ indefinitely; lifecycle sau 1 tháng — đúng pattern backup. |
| C | Standard-IA vẫn đắt hơn Glacier cho archive lâu năm không retrieve. |
| D | One Zone-IA rẻ hơn Standard-IA nhưng vẫn đắt hơn Deep Archive; mất AZ resilience. |

**Ghi nhớ:** Backup/archive lâu, hiếm access → **Lifecycle → Glacier Deep Archive**.
