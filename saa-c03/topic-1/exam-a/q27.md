# Q27 — Share CloudWatch dashboard with external product manager

## Question

**EN:** A company is launching a new application and will display application metrics on an Amazon CloudWatch dashboard. The company's product manager needs to access this dashboard periodically. The product manager does not have an AWS account. A solutions architect must provide access to the product manager by following the principle of least privilege. Which solution will meet these requirements?

**VI:** App hiển thị metric trên **CloudWatch dashboard**. **Product manager** cần xem định kỳ, **không có AWS account**. Cấp quyền theo **least privilege**. Giải pháp nào phù hợp?

---

## Options

### A

**EN:** Share the dashboard from the CloudWatch console. Enter the product manager's email address, and complete the sharing steps. Provide a shareable link for the dashboard to the product manager.

**VI:** **Share dashboard** từ CloudWatch console, nhập **email** PM, hoàn tất share, gửi **link**.

### B

**EN:** Create an IAM user specifically for the product manager. Attach the CloudWatchReadOnlyAccess AWS managed policy to the user. Share the new login credentials with the product manager. Share the browser URL of the correct dashboard with the product manager.

**VI:** Tạo **IAM user** + `CloudWatchReadOnlyAccess`, gửi credential + URL dashboard.

### C

**EN:** Create an IAM user for the company's employees. Attach the ViewOnlyAccess AWS managed policy to the IAM user. Share the new login credentials with the product manager. Ask the product manager to navigate to the CloudWatch console and locate the dashboard by name in the Dashboards section.

**VI:** IAM user + `ViewOnlyAccess`, PM tự tìm dashboard trong console.

### D

**EN:** Deploy a bastion server in a public subnet. When the product manager requires access to the dashboard, start the server and share the RDP credentials. On the bastion server, ensure that the browser is configured to open the dashboard URL with cached AWS credentials that have appropriate permissions to view the dashboard.

**VI:** **Bastion** public + RDP + browser cache AWS credential xem dashboard.

---

## Answer

**Đáp án: A**

| Option | Vì sao loại / chọn |
|--------|---------------------|
| **A ✅** | CloudWatch **share dashboard** qua email/link — viewer **không cần AWS account**, chỉ xem dashboard cụ thể = **least privilege**. |
| B | IAM user = full AWS console read CloudWatch — rộng hơn cần thiết; PM không có account sẵn. |
| C | ViewOnlyAccess toàn account — quá rộng; vẫn cần IAM login. |
| D | Bastion + shared credentials — security nightmare, overhead cao. |

**Ghi nhớ:** External viewer chỉ cần 1 dashboard → **CloudWatch dashboard sharing**.
