# Q18 — Image compression pipeline (Choose TWO)

## Question

**EN:** An application development team is designing a microservice that will convert large images to smaller, compressed images. When a user uploads an image through the web interface, the microservice should store the image in an Amazon S3 bucket, process and compress the image with an AWS Lambda function, and store the image in its compressed form in a different S3 bucket. A solutions architect needs to design a solution that uses durable, stateless components to process the images automatically. Which combination of actions will meet these requirements? **(Choose two.)**

**VI:** Team phát triển thiết kế microservice **nén ảnh lớn** thành ảnh nhỏ hơn. User upload qua web → lưu **S3 bucket A** → **Lambda** nén → lưu **S3 bucket B**. **Solutions architect** cần thiết kế bằng thành phần **durable, stateless**, xử lý **tự động**. **Chọn hai** hành động phù hợp.

---

## Options

### A

**EN:** Create an Amazon Simple Queue Service (Amazon SQS) queue. Configure the S3 bucket to send a notification to the SQS queue when an image is uploaded to the S3 bucket.

**VI:** Tạo **SQS queue**. Cấu hình **S3 event notification** gửi tới queue khi có upload.

### B

**EN:** Configure the Lambda function to use the Amazon Simple Queue Service (Amazon SQS) queue as the invocation source. When the SQS message is successfully processed, delete the message in the queue.

**VI:** **Lambda** dùng **SQS** làm event source. Xử lý xong thì **delete message**.

### C

**EN:** Configure the Lambda function to monitor the S3 bucket for new uploads. When an uploaded image is detected, write the file name to a text file in memory and use the text file to keep track of the images that were processed.

**VI:** Lambda **poll S3**, ghi tên file vào **text file in-memory** để track đã xử lý.

### D

**EN:** Launch an Amazon EC2 instance to monitor an Amazon Simple Queue Service (Amazon SQS) queue. When items are added to the queue, log the file name in a text file on the EC2 instance and invoke the Lambda function.

**VI:** **EC2** monitor SQS, log file name trên disk, invoke Lambda.

### E

**EN:** Configure an Amazon EventBridge (Amazon CloudWatch Events) event to monitor the S3 bucket. When an image is uploaded, send an alert to an Amazon Simple Notification Service (Amazon SNS) topic with the application owner's email address for further processing.

**VI:** **EventBridge** monitor S3, gửi **SNS email** cho owner xử lý thủ công.

---

## Answer

**Đáp án: A và B**

**Note:** Pipeline durable + stateless: **S3 event → SQS** (buffer) → **Lambda** consume queue và delete message sau khi xử lý; tránh poll S3/in-memory state hoặc EC2 monitor.

| Option | Vì sao loại / chọn |
|--------|---------------------|
| **A ✅** | S3 → **SQS** = buffer **durable**, decouple upload và processing — stateless. |
| **B ✅** | **Lambda poll SQS** (event source mapping), delete sau success — at-least-once + idempotent handler. |
| C | In-memory text file = **stateful**, mất khi container die — vi phạm yêu cầu. |
| D | EC2 monitor queue — **không stateless**, thêm server cần vận hành. |
| E | SNS email alert — **không tự động xử lý** pipeline, không durable processing. |

**Pipeline chuẩn:** `S3 upload → SQS → Lambda → S3 (compressed)`
