# Q30 — Cost-effective RDS for monthly 48h tests

## Question

**EN:** A development team runs monthly resource-intensive tests on its general purpose Amazon RDS for MySQL DB instance with Performance Insights enabled. The testing lasts for 48 hours once a month and is the only process that uses the database. The team wants to reduce the cost of running the tests without reducing the compute and memory attributes of the DB instance. Which solution meets these requirements MOST cost-effectively?

**VI:** Team dev chạy test tài nguyên nặng **48 giờ mỗi tháng** trên **Amazon RDS for MySQL** (general purpose, có Performance Insights). Đây là **use duy nhất** của database. Team muốn **giảm chi phí** nhưng **không giảm CPU/RAM** của DB instance. Giải pháp nào **tiết kiệm nhất**?

---

## Options

### A

**EN:** Stop the DB instance when tests are completed. Restart the DB instance when required.

**VI:** **Stop** RDS khi test xong, **start** lại khi cần.

### B

**EN:** Use an Auto Scaling policy with the DB instance to automatically scale when tests are completed.

**VI:** **Auto Scaling policy** trên RDS instance.

### C

**EN:** Create a snapshot when tests are completed. Terminate the DB instance and restore the snapshot when required.

**VI:** Tạo **snapshot** → **terminate** instance → **restore snapshot** khi cần test.

### D

**EN:** Modify the DB instance to a low-capacity instance when tests are completed. Modify the DB instance again when required.

**VI:** **Downsize** instance khi xong test, scale up lại khi cần.

---

## Answer

**Đáp án: C**

**Note:** RDS chỉ dùng 48h/tháng, giữ nguyên instance size → **snapshot → terminate → restore** khi cần test; chỉ trả snapshot storage phần lớn thời gian, không trả compute idle.

| Option | Vì sao loại / chọn |
|--------|---------------------|
| A | Stop vẫn **trả storage** EBS full; compute stop nhưng 720h idle/tháng vẫn tốn storage instance. |
| B | RDS **không có Auto Scaling** instance size như EC2 ASG — không hợp lệ. |
| **C ✅** | **Snapshot + terminate** — chỉ trả **snapshot storage** (~$0.023/GB) phần lớn tháng; restore cùng class khi test — **giữ nguyên compute/RAM**, rẻ nhất cho dùng 48h/tháng. |
| D | Downsize = **giảm compute/memory** — vi phạm yêu cầu đề. |

**Ghi nhớ:** RDS dùng ít giờ/tháng, giữ size lớn → **snapshot → delete → restore** khi cần.
